2. 完整接口一览
==============================================================
add_messages() 批量加 3 条 → 3 条
add_message() 再加 1 条 → 4 条

第 1 条是: SystemMessage → 你是一个乐于助人的助手。

接口方法小结：
  .messages            读（property，不是方法，别加括号）
  .add_messages(list)  批量写【推荐】
  .add_message(msg)    单条写
  .add_user_message(s) / .add_ai_message(s)   便捷写法
  .clear()             清空
  .aadd_messages / .aget_messages / .aclear   异步版本（默认内部转同步）

>> 官方建议：更新历史时优先用 add_messages()，
   别用 add_user_message + add_ai_message 各调一次——
   如果底层是数据库，那就变成两次 IO 往返了。

   【一个能读能写的消息列表 + 约定好的接口】。
