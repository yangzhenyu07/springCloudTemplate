5. 三条路线怎么选
==============================================================
  方案                      适用场景                  特点
  ------------------------------------------------------------------------------
  StrOutputParser         只要纯文本                 最简单，做打字机必备
  JsonOutputParser        要 dict，字段简单           灵活，不校验字段
  PydanticOutputParser    要对象 + 字段校验            IDE 补全好，缺字段会报错
  with_structured_output  字段多/结构复杂/要求稳          API 层强制格式，最可靠

  决策建议：
   · 只是要一段文字            → StrOutputParser
   · 1-3 个简单字段            → JsonOutputParser / PydanticOutputParser
   · 嵌套结构、列表、可选字段  → with_structured_output
   · 要接数据库/下游接口       → with_structured_output（格式有保证）

  另外两个实用参数：
   · include_raw=True   同时返回原始 AIMessage，方便排查问题
   · 传 TypedDict 或 JSON Schema 也行，不一定要 pydantic 类
