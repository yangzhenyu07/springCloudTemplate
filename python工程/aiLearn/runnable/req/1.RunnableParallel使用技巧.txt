1. 两种写法：RunnableParallel(...) vs 字典字面量
==============================================================
【写法一】RunnableParallel(joke=..., poem=...)
  构造出来的类型 : RunnableParallel
  有 invoke 方法 : True  <-- 直接就能用
  结果键         : ['joke', 'poem']

【写法二】{'joke': ..., 'poem': ...}
  拿在手里是什么 : dict
  有 invoke 方法 : False  <-- 裸 dict 不是 Runnable！
  直接 invoke 会炸: 'dict' object has no attribute 'invoke'

>> 所以「两种写法等价」是有【前提】的：
   裸 dict 本身不是 Runnable，只有在参与 LCEL 组合时才会被自动转换。

   把 dict 变成 Runnable 的两种方式：
    ① dict | RunnableLambda(fn)  → RunnableParallel
    ② coerce_to_runnable(dict)   → RunnableParallel

   （原理：| 的运算符重载。dict 没有 __or__，Python 转而调用
     右边 Runnable 的 __ror__，langchain 在其中完成转换。）

【验证】两种写法跑出来的结果:
  RunnableParallel 版 → ['joke', 'poem']
  字典转换版         → ['joke', 'poem']
  joke 分支: 为什么程序员分不清万圣节和圣诞节？
因为 Oct 31 == Dec 25。 ...
  poem 分支: 《程序员》
代码是夜，
bug 是星；
咖啡续命，
上线天明。 ...

>> 结论：
   · 单独放着：RunnableParallel 是 Runnable，dict 不是 —— 不等价
   · 放进管道：dict 会被自动转成 RunnableParallel —— 等价
   · 日常推荐写 {'joke': ..., 'poem': ...} | 后续处理，更简洁

==============================================================
  分支A: A 线程=ThreadPoolExecutor-3_0 耗时=1.50s
  分支B: B 线程=ThreadPoolExecutor-3_1 耗时=1.50s

  总耗时: 1.50s
  串行预期: 3.00s  |  并行预期: 1.50s

  ✅ 结论：是真并发。invoke() 内部用线程池跑各个分支。
     >> 两个分支跑在不同的线程上（看上面的线程名）。
     >> 所以 IO 密集的场景（调模型、调 API）收益很大。

5. 坑：dict 和 fn 组合时的 TypeError
==============================================================
  | 是运算符重载，要求【两边至少一边是 Runnable】。
  dict 和 function 都是 Python 内置类型，谁都没有 __or__，于是报错。

  写法                            结果
  ----------------------------------------------
  dict | Runnable(fn)           ✅ -> RunnableSequence
  RunnableParallel | fn         ✅ -> RunnableSequence
  dict | RunnableLambda(fn)     ✅ -> RunnableSequence
  dict | fn                     ❌ TypeError: unsupported operand type(s) for |

  >> 解法很简单：保证至少一边是 Runnable
     ① 右边自带 Runnable（实际项目最常见，因为右边是 prompt/model）
     ② 右边包一层 RunnableLambda(fn)
     ③ 左边显式写 RunnableParallel(a=fn)

  >> 顺带解释了为什么旧文件 2 能跑：
     它写的是 {dict} | prompt，右边 prompt 是 Runnable，所以自动转换生效。
