3. RunnablePassthrough 使用技巧（DeepSeek + 最新 API）

==============================================================
1. RunnablePassthrough 单独用：输入=输出
==============================================================
  输入: {'a': 1, 'b': 2}
  输出: {'a': 1, 'b': 2}

  >> 单独用确实没意义，它的价值在 .assign() 和管道里的占位：
     想在管道中间什么都不做地透传一段，就用它。

==============================================================
2. assign：保留原字段 + 追加新字段
==============================================================
  输入: {'query': ..., 'user_id': 'u_001'}
  输出键: ['query', 'user_id', 'context']
  context 字段: - 退款规则：7天无理由退款，商品需完好；卖家超时未发货可全额退款。 ...
  user_id 是否在原样保留: True

  >> 注意 user_id 完全没动——这就是 assign 和 RunnableParallel
     最大的区别：不用把每个原字段抄一遍。

==============================================================
3. 对比：RunnableParallel 要手写所有字段
==============================================================
  输入字段: ['query', 'user_id', 'session_id']
  assign 输出字段   : ['query', 'user_id', 'session_id', 'context']
  parallel 输出字段 : ['context', 'query', 'user_id', 'session_id']
  两者是否等价: True

  >> 字段越多，assign 越省事。
     实战建议：需要保留大部分原字段 → assign；
              只要少数几个字段     → RunnableParallel + pick

==============================================================
4. 实测：assign 多个字段时并发吗
==============================================================
  结果: {'origin': 'keep', 'a': 'A@ThreadPoolExecutor-4_0', 'b': 'B@ThreadPoolExecutor-4_1'}
  总耗时: 1.20s（串行应为 2.40s，并发约 1.20s）

  ✅ assign 内部也是并发的。
     >> 它等价于 RunnableAssign(RunnableParallel(...))，
        所以天然继承了 RunnableParallel 的线程池并发。

==============================================================
5. 多次 assign 链式叠加
==============================================================
  最终字段: ['query', 'ctx', 'ctx_len', 'summary']
  summary: 检索到 29 字资料
  ctx_len: 29

  >> assign 可以无限往后接，后面的能读到前面算出来的字段。
     这让你能把复杂的数据准备过程拆成一串小步骤，可读性好。

==============================================================
6. RunnableAssign —— assign 的底层类
==============================================================
  Passthrough.assign(...)          : RunnableAssign
  RunnableAssign(RunnableParallel) : RunnableAssign
  两者输出是否一致: True

  >> 平时写 .assign() 就够，知道有这个类是为了看懂别人的代码和报错栈。
