1. dict 字面量为什么能接 |
==============================================================
  原始 dict 的类型: dict
  dict | prompt 之后: RunnableSequence
  管道各段类型: ['RunnableParallel', 'ChatPromptTemplate']

  >> 关键：dict.__or__ 不存在，Python 改调用右边 prompt 的 __ror__，
     langchain 在里面把 dict 转成了 RunnableParallel，
     并把 dict 里的每个 callable 包成 RunnableLambda。

  >> 所以 dict 字面量 == RunnableParallel 的语法糖。

4. RunnablePick —— 只保留需要的字段
==============================================================
全部字段: {'a': 'A值', 'b': 'B值', 'c': 'C值'}
pick(['a','c']): {'a': 'A值', 'c': 'C值'}

  >> 用途：下游只需要部分字段时，用 pick 收窄数据流，
     管道意图更清晰，也避免把无关数据往后传。
