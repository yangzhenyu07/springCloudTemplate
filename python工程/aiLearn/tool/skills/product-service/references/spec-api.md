# 商品规格字段说明

> 本文件是 **L3 资源**：平时不在上下文里，只有 SKILL.md 指路、模型主动读时才加载。
> 这样规格字段再长也不占上下文 —— 这是渐进式披露的核心收益。

## 字段口径

| 字段 | 含义 | 单位 | 注意 |
|---|---|---|---|
| `size` | 外包装尺寸 | cm | 长×宽×高，顺序固定 |
| `weight` | 毛重 | g | 含包装，不是净重 |
| `material` | 主体材质 | - | 多种材质用 `/` 分隔 |
| `color` | 颜色 | - | 用中文名，不用色号 |

## 常见坑

1. **毛重 vs 净重**：物流报价要用毛重（含包装），用户问「东西多重」通常指净重。
   回答时说明是哪个，别混着说。

2. **尺寸顺序**：`30x15cm` 表示长 30、宽 15，**高不单独给出**（扁平件高忽略）。
   立体商品会写成 `30x15x10cm` 三位数。

3. **材质多值**：`ABS/铝合金` 表示主体 ABS、支架铝合金。
   用户问「是不是全金属」时，要看有没有非金属成分，不能直接答「是」。

## 缺失值处理

接口返回的规格可能缺字段。缺了就如实说「该商品未提供此参数」，
**不要**用同类商品的值去补，也不要编。
