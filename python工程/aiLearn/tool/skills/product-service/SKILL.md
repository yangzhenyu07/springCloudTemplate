# 商品服务

## 一、只有三种问题归我管

| 用户说法 | 动作 | 工具 |
|---|---|---|
| 「还有货吗」「库存多少」 | 查库存 | `product_stock` |
| 「有没有 XX」「搜一下 XX」 | 搜索 | `product_stock` 按 ID 查 |
| 「尺寸/材质/参数/配置」 | 查规格 | 先读 `references/spec-api.md` |

## 二、查库存

调 `product_stock(product_id=商品ID)`。

- **必须要有商品 ID**。用户只说「键盘」没给 ID 时，先问型号或 ID，不许拿关键词去查库存。
- 返回里的仓库位置可以顺带告诉用户（影响收货时间）。

## 三、查规格参数

规格字段多、口径杂，**先读 `references/spec-api.md`** 再回答，别凭印象。
（这就是 L3 渐进式披露：规格文档平时不在上下文里，要用才读。）

## 四、回答规范

1. 库存是**实时数字**，必须来自工具，不许估算。
2. 「有没有货」= 库存 > 0，直接回答有/没有，再补具体数字。
3. 缺商品 ID 就问，不要瞎猜一个 ID 去查。
